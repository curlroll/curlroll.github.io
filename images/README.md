# 実績ギャラリー用の写真フォルダ

このフォルダに作例写真を入れると、トップページの「制作実績」ギャラリーに表示されます。

## ファイル名のルール
- 1枚目：`gallery-01.jpg`
- 2枚目：`gallery-02.jpg`
- 以降 `gallery-03.jpg` … と連番で追加

`index.html` の Gallery セクション（`<figure class="shot ...">`）の
`src` / `data-full` / `data-caption` を、増やした写真に合わせて編集してください。
写真ファイルが無いスロットは自動で「準備中」表示になります。

## いい写真を撮るコツ（HP映え）
1. **背景は1色**（白い紙・木のテーブル・黒い布など）。生活感のあるものを写さない。
2. **自然光**（窓際）で撮る。直射日光の強い影は避ける。
3. ポーチ類は**中に詰め物**をして立体感を出す。Tシャツは平置きでシワを伸ばす。
4. **正方形（1:1）にトリミング**するとタイルにぴったり収まる。
5. 1枚あたり **1〜2MB程度**に圧縮（表示が速くなる）。

## 表示サイズの目安
- タイルは正方形（`object-fit:cover`）で中央トリミング表示
- クリックで拡大（ライトボックス）表示に対応済み
